第 1 步 · BIOS 里开过 CPU 虚拟化吗？

Win + R 输 msinfo32 可查；Intel 需开 VT-X + VT-D，AMD 需开 SVM + IOMMU。

第 2 步 · 你电脑上中了几条？（多选）

不确定的全勾上也没关系，诊断脚本会再核实一遍。
