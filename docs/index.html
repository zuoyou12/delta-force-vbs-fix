PROBLEM

这是什么弹框，为什么要修？

腾讯游戏安全团队与微软团队合作，要求部分账号开启系统硬件安全特性（CPU 虚拟化）以更好地保障对局安全。开启这些功能不会侵犯隐私或影响电脑使用。

很多玩家 BIOS 里 已开启 VT-X/VT-D 或 SVM/IOMMU，但游戏里仍弹框，原因通常是 Windows 内部还有占用 VT-x 的安全特性没关。官方梳理出 4 种情况，本工具把它们对应到一组脚本。

— 参考：gamesafe.qq.com/article/1181.shtml

WIZARD

交互式诊断向导

按 3 步走，最后给出你应运行 fix-vbs.bat 的具体菜单编号。

第 1 步：你是否已在 BIOS 中开启 CPU 虚拟化？

用 Win + R 输 msinfo32 可查主板品牌。Intel 平台需开 VT-X + VT-D；AMD 平台需开 SVM + IOMMU。

第 2 步：重启电脑后，弹框是否仍在？

BIOS 改完必须重启。重启后再次进游戏验证。

第 3 步：勾选你目前的情况

勾选所有符合的项目，可多选。系统会基于勾选项给出对应的官方情况与脚本菜单。
